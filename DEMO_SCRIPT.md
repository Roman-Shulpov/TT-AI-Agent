# Демонстрация проекта

Готовые реальные записи находятся в [demo](demo/README.md). Для сдачи можно отправить их
вместе с репозиторием. Первая показывает ввод, отметку checkbox и фильтрацию; вторая —
навигацию между карточками, сохранение фактов, сравнение и восстановление после ошибки.

Для повторения откройте `start.cmd` и введите новую задачу из README, изменив названия или цель.
Для записи используйте `python -m browser_agent --record artifacts/my-video`.
Браузер надо закрыть штатно после завершения, чтобы Playwright сохранил WebM.

На защите объясните: модель выбирает Action, Python проверяет схему и runtime ID, выполняет
действие, снова читает страницу. Память ограничена; итог отдельно проверяет Verifier.
Не называйте тест с mock моделью доказательством автономности. Ошибку или остановку показывайте
как ошибку/остановку. Для записи используйте только учебные страницы без личных данных.
