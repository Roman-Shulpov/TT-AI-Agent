# Сообщение ментору

Здравствуйте! Отправляю тестовое задание — браузерного AI-агента на Python.

Репозиторий: https://github.com/Roman-Shulpov/TT-AI-Agent
Видео и результаты: https://github.com/Roman-Shulpov/TT-AI-Agent/blob/main/demo/README.md

Агент принимает задачу обычным текстом, выбирает действия по текущей странице и управляет
видимым Chromium. Есть ограничение контекста, обработка ошибок и отдельная проверка результата.
В репозитории описаны установка, архитектура, тесты и ограничения. Реальные видео показывают
две задачи на разных сайтах. При разработке использовал Codex.

Основной запуск использует Codex CLI через вход ChatGPT, без отдельного API-ключа;
официальный OpenAI SDK и экспериментальный Ollama adapter также реализованы.
