# Browser AI Agent

Агент принимает задачу обычным текстом и работает в видимом Chromium. Модель выбирает
следующее действие по текущей странице; Python проверяет его аргументы и выполняет через
Playwright. В коде нет сценариев и селекторов для конкретных сайтов.

## Быстрый запуск

На компьютере, где проект готовился, откройте [start.cmd](start.cmd) двойным щелчком и
введите задачу в терминале. Используется уже выполненный вход в Codex; отдельный API-ключ
не нужен. Браузер откроется автоматически.

Для установки на другом Windows-компьютере нужны Python 3.11+, Node.js и доступ к Codex:

```powershell
npm install -g @openai/codex
codex login
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe -m browser_agent
```

Программа запрашивает цель в терминале. `/stop` или Ctrl+C останавливает работу.
Браузер остаётся открытым до Enter после результата. Для входа на сайт сначала запустите
`python -m browser_agent --login --start-url URL` и войдите вручную: отдельный профиль
сохранит сессию. `python -m browser_agent --help` показывает остальные параметры, включая
`--task`, `--record DIR` и `--dry-run`.

## Как устроен агент

```text
Цель → снимок страницы → решение модели → проверка аргументов и риска
     → действие Playwright → новый снимок → проверка результата
```

`browser_agent/agent.py` управляет циклом. `observation.py` извлекает видимый текст и
элементы, а `models.py` задаёт строгие схемы команд. `context.py` хранит исходную цель,
последние действия и нужные цитаты в ограниченном объёме. `tools.py` запрашивает
подтверждение перед чувствительными действиями. Перед сообщением об успехе отдельный
вызов модели проверяет свежие данные страницы.

Доступны общие команды: переход, клик, ввод текста, выбор в списке, прокрутка, возврат,
ожидание, нажатие клавиши, смена вкладки, сохранение цитаты, вопрос пользователю и
завершение. Модель выбирает их во время выполнения задачи; она не может отправлять
собственный Python, JavaScript или CSS-селекторы на исполнение.

По умолчанию используется авторизованный Codex CLI с выводом по JSON-схеме.
Интеграция через официальный OpenAI SDK (`LLM_PROVIDER=openai`) и локальный Ollama
(`LLM_PROVIDER=ollama`) также реализованы. Для OpenAI нужен собственный API-ключ;
локальный вариант требует установленного Ollama и модели. Эти настройки приведены
в [.env.example](.env.example). Инструмент разработки — Codex.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\ruff.exe check .
.\.venv\Scripts\ruff.exe format --check .
```

Основной набор: **53 passed, 3 skipped**. Отдельный тест с настоящей моделью и видимым
браузером, а также два автономных публичных прогона прошли успешно. Условия и точные
результаты записаны в [TEST_REPORT.md](TEST_REPORT.md). Видео показывают полные реальные
запуски; данные задач и итоговые снимки находятся рядом с ними.

Агент работает с видимым DOM, поэтому CAPTCHA, canvas, закрытый shadow DOM и сложные
жесты требуют ручной помощи или пока не поддерживаются. Подтверждения снижают риск
нежелательных действий, но модель и её проверка результата могут ошибаться.
