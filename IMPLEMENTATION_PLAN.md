# План реализации

1. Проверить среду и официальные API. Выбрать Python + asyncio + Playwright + OpenAI Responses.
2. Разделить конфигурацию, схемы, браузер, наблюдение, tools, провайдер, память, safety и цикл.
3. Снимать ограниченный видимый DOM; выдавать новые runtime IDs и сохранять ссылки на узлы.
4. Получать один native function call, проверять Pydantic, исполнять только известный tool.
5. Хранить последние шаги, ограниченный журнал старых результатов и подтверждённые цитаты.
6. Добавить Actor + final Verifier, повторное наблюдение, лимиты ошибок и обнаружение циклов.
7. Проверить реальный Chromium, динамический UI, формы, вкладки, stale nodes и отказ подтверждения.
8. Проверить официальный SDK через HTTP mock; live API проверять только при наличии ключа.
9. Проверить два публичных UI универсальными browser primitives, отдельно от live-agent demo.
10. Подготовить README, честный отчёт проверок, сценарий видео и материалы защиты.

Никаких сценариев по словам задачи или селекторов конкретного сайта в core.

## Реализованное дополнение

Для сдачи без отдельного API-ключа добавлен официальный Codex CLI adapter через существующий
вход ChatGPT. Успешные реальные записи и тесты приведены в TEST_REPORT и demo/README.
Локальный Ollama adapter оставлен экспериментальным после неуспешных попыток малых моделей.
