# Финальный результат

## 1. Что готово

Браузерный AI-агент на Python, принимающий произвольную задачу. Есть реальные успешные
прогоны, видео и воспроизводимые тесты. [Репозиторий](https://github.com/Roman-Shulpov/TT-AI-Agent).

## 2. Демонстрации

[Список дел, 10 шагов](demo/demo.mp4) и [сравнение товаров, 9 шагов](demo/books.mp4).
Это полные реальные записи видимого Chromium, без ускорения и подмены действий.
[Цели, доказательства и исходные WebM](demo/README.md).

## 3. Соответствие ТЗ

Произвольная цель → observation → решение модели → валидация → Playwright → новый observation.
Нет workflows, доменов и селекторов конкретных сайтов в core. Контекст ограничен, есть
human input, обработка ошибок, защита от циклов и Actor + финальный Verifier.

## 4. Структура

`cli.py` — ввод; `agent.py` — цикл; `models.py` — строгие tools; `browser.py` — Playwright;
`observation.py`/`extract.js` — DOM; `context.py` — память; `tools.py`/`safety.py` — исполнение;
`providers.py` — выбор модели; `codex_provider.py`, `llm.py`, `ollama_provider.py` — backend.

## 5. Запуск

На подготовленном компьютере откройте `start.cmd`. Введите задачу в терминале.
На другом компьютере выполните установку по [README](README.md). Видимый браузер открывается
автоматически. Отдельный API-ключ для основного варианта не нужен.

## 6. Модель

По умолчанию Codex CLI + gpt-5.5 через существующий вход ChatGPT; используются лимиты Codex.
CLI возвращает JSON по схеме, его инструменты отключены. Playwright выполняет наши tools.
Официальный OpenAI SDK реализован отдельно; Ollama оставлен экспериментальной альтернативой.
Авторизационные токены CLI проект не извлекает и не копирует.

## 7. Тестирование

`python -m pytest -q`, `ruff check .`, `ruff format --check .`.
`RUN_LIVE_TESTS=1` включает настоящий model test. Подробности в [TEST_REPORT](TEST_REPORT.md).

## 8. Результаты

53 автоматических проверки прошли; live fixture отдельно прошёл. Два публичных автономных
прогона завершились успешно. Вторая задача показала восстановление после неверной цитаты.

## 9. Пример задачи

Открой https://demo.playwright.dev/todomvc/. Добавь три задачи: «Прочитать README»,
«Запустить тесты», «Записать демонстрацию». Отметь первую выполненной и покажи активные.
Можно менять цель и сайт: последовательность действий выбирается моделью во время запуска.

## 10. Ограничения

CAPTCHA/login — вручную; DOM-first не понимает canvas. Модель и verifier могут ошибаться.
Safety — эвристики, не security sandbox. OpenAI SDK вживую с API-ключом не проверялся.
Локальные маленькие модели не прошли наши задачи; основной backend — Codex.
