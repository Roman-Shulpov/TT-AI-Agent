## Независимая сверка результата

**TodoMVC:** конечный URL заканчивается на `#/active`; на странице видны только `Run tests`
и `Record demo`, счётчик `2 items left`. `Read README` отмечена выполненной.
Проверены конечный DOM и скриншот. Память сжала 3 старых шага.

**Books:** открыты обе карточки Travel, сохранены точные цитаты с URL:
`It's Only the Himalayas` — £45.17; `Full Moon over Noah’s Ark: An Odyssey to Mount Ararat and Beyond`
— £49.43. Разница **£4.26**. Первый запрос сохранения цитаты был отклонён, потому что строка
не совпала с visible text; модель сама исправила цитату. Память сжала 2 шага.

**Live fixture:** настоящая модель сама открыла каталог, использовала поиск, добавила рюкзак
в корзину и завершила задачу за 5 шагов. Независимый assert проверил текст корзины.
Автоподтверждение в этом тесте разрешено только для изолированной локальной HTML-фикстуры.
В публичных записях запрос подтверждения остановил бы сценарий, а не получил автоматическое YES.

## Что покрывает основной набор

Строгие Pydantic-схемы; URL и runtime IDs; ограничение памяти и цитаты; обнаружение циклов;
policy и подтверждения; stale DOM; скрытые/offscreen элементы; checkbox/select;
shadow DOM, iframe, вкладки; controller loop и отказ verifier; retry и HTTP-mock OpenAI SDK;
Ollama native tools и bounded history; Codex stdin, JSON schema, отключённые integrations,
санитизация ошибок. Browser tests работают с настоящим Chromium.

## Неудачные попытки и ограничения

Qwen3 4B и Qwen2.5 7B через локальный Ollama делали неверные действия, повторяли переходы,
создавали дубликаты или не соблюдали схему. Эти прогоны **не засчитаны успешными**.
Ollama adapter оставлен экспериментальным. В сдаваемых видео используется Codex.
Последовательности под конкретные сайты в core не добавлялись.

OpenAI Responses реализован и проверен через HTTP mock, но живой облачный вызов именно через
этот SDK не выполнялся: отдельного API-ключа нет. Codex CLI — самостоятельный backend,
его успешный запуск не выдаётся за проверку Responses API с API-ключом.

Почта, реальные покупки и отправка откликов не проверялись: нет пользовательских сессий,
а публичные учебные сайты позволяют показать работу без необратимых действий.
Два успешных публичных примера не являются benchmark и не гарантируют работу на любом сайте.
CAPTCHA, canvas, закрытый shadow DOM, drag/drop и сложные widgets остаются ограничениями.

## Воспроизведение

Установить зависимости по README, выполнить `codex login`, затем основной набор и live test.
Для новой записи используйте `scripts/record_demo.py --task "..." --output artifacts/new-demo`.
Каталог должен быть новым. Записывайте только публичные учебные данные: recorder сохраняет
цель, решения и видимое содержимое страницы. Сам агент принимает произвольную задачу.
